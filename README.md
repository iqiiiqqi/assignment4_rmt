# Application of Machine Learning Algorithms and Big Data Analysis to Detect Fraudulent Transactions in the Banking Sector

## Project Overview

This project focuses on the application of machine learning algorithms and big data analysis techniques to detect fraudulent transactions in the banking sector.

The main objective is to compare different machine learning models and evaluate their effectiveness in identifying fraudulent transactions, particularly when dealing with highly imbalanced datasets. The project also considers model performance, computational efficiency, and interpretability.

## Research Objectives

The project aims to:

- Compare the performance of different machine learning algorithms for fraud detection.
- Evaluate class-imbalance handling techniques, including class weighting, random under-sampling, and SMOTE.
- Assess model performance using appropriate evaluation metrics, with a focus on Precision-Recall AUC (PR-AUC).
- Explore the potential use of Apache Spark for processing large-scale transaction data.
- Examine model interpretability using SHAP (SHapley Additive exPlanations).

## Datasets

The research uses two publicly available datasets:

1. **European Credit Card Fraud Detection Dataset** – contains 284,807 credit card transactions, including fraudulent and legitimate transactions.
2. **PaySim Mobile Money Dataset** – contains 6,362,620 simulated mobile money transactions.

These datasets provide different transaction environments for evaluating fraud detection approaches.

## Machine Learning Models

The study considers the following algorithms:

- Logistic Regression
- Random Forest
- XGBoost
- CatBoost
- Multilayer Perceptron (MLP)
- Stacking Ensemble
- Isolation Forest
